# honrp brand guide

## Visual direction

A compact, original visual identity for a Heroes of Newerth → Discord Rich Presence bridge. The app icon is deliberately flat and geometric so it stays recognizable at small sizes. The GitHub banner and README artwork add restrained atmosphere without adding detail to the icon itself.

## Core colors

| Name | Hex | Use |
|---|---|---|
| Night | `#160D29` | Icon background / dark surfaces |
| Purple | `#833BFA` | App border / brand accent |
| Deep Purple | `#6425D6` | Secondary accent |
| Gold | `#FFB627` | Hood silhouette |
| Gold highlight | `#FFD34E` | Eyes |
| Lavender | `#BE8BFF` | Bridge / secondary text |
| White | `#FFFFFF` | Chat bubble / primary text |

## Symbol meaning

- Hood and eyes: HoN / game identity.
- Three-arch bridge: the bridge between the game and Discord.
- Chat bubble: Rich Presence and communication; it is not the Discord logo.

## Icon guidance

Use `app-icons/windows/honrp.ico` for Windows executable and window resources; `app-icons/macos/honrp.icns` for macOS app bundles; and the PNGs under `app-icons/linux/hicolor/` for Linux desktop entries. Use the 16/24/32 px optimized PNGs for small surfaces. The design intentionally contains no tray variants: honrp is not intended to live in the system tray.

## GitHub usage

- `github/social-preview-1280x640.png`: repository social preview.
- `github/readme-banner-1600x450.png`: README header.
- `github/avatar-512.png`: repository avatar or profile graphic.
- `brand/honrp-logo-lockup.svg`: scalable wordmark + descriptor.

All SVG assets are editable vector source.
