# Brand assets

- `banner.png` — 1280×640, for the GitHub README and the repository's
  **Settings → Social preview** image.
- `icon.png` — 1024×1024 square mark, for a Discord application icon, a tray
  icon, or docs.

Both are original honrp artwork (no Heroes of Newerth/Juvio assets) and are
released under the same MIT license as the project.

To set the GitHub card image: **Settings → Social preview → Edit → upload
`banner.png`**. GitHub has no API for that field, so it's one click.
