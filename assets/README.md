# Brand assets

- `icon.png` — 1024×1024 rounded-square mark, for a Discord application icon, a
  tray icon, or docs.
- `states.png` — 1280×580 overview of the six presence states used in the README.
  Generated by `render_states.py` from the same strings `build_activity()` emits;
  rerun it after changing labels:

  ```bash
  python3 assets/render_states.py
  ```

Both are original honrp artwork — a shield monogram and neutral card shapes, no
Heroes of Newerth or Juvio assets — and are released under the same MIT license
as the project.

`states.png` is an illustration, not a screenshot: Discord composes the real card
from the running game, so a genuine capture has to come from someone playing
with the mod loaded. Drop it in as `screenshot.png` when available.
