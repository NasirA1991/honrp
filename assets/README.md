# Brand assets

- `banner.png` — 1280×640 wordmark banner for the README and the repository's
  **Settings → Social preview** image.
- `icon.png` — 1024×1024 rounded-square mark, for a Discord application icon, a
  tray icon, or docs.

Both are original honrp artwork — a shield monogram and a condensed wordmark, no
Heroes of Newerth or Juvio assets — and are released under the same MIT license
as the project.

To set the GitHub card image: **Settings → Social preview → Edit → upload
`banner.png`**. GitHub has no API for that field, so it's one click.

There is deliberately no screenshot of a Discord card here: Discord renders it
from the running game, so a genuine capture has to come from someone playing
with the mod loaded. Drop it in as `screenshot.png` when available.
