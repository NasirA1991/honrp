# Brand assets

  tray icon, or docs.

The icon is original honrp artwork — a shield monogram, no Heroes of Newerth or
Juvio assets — and is released under the same MIT license as the project.

game, so a genuine capture has to come from someone playing with the mod loaded.
Drop it in as `screenshot.png` when available.
