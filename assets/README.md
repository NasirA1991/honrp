# Brand assets

- `icon.png` — 1024×1024 rounded-square mark, for a Discord application icon, a
  tray icon, or docs.
- `states-discord.png` — 1280×380 Discord-style preview of the six presence states
  used in the README.
  Generated by `render_states.py` from the same strings `build_activity()` emits;
  rerun it after changing labels:

  ```bash
  python3 assets/render_states.py
  ```

Both are original honrp artwork — a shield monogram and neutral card shapes, no
Heroes of Newerth or Juvio assets — and are released under the same MIT license
as the project.

`states-discord.png` is a Discord-style mockup, not a screenshot: the client uses its
own font, spacing and app artwork. The strings are generated from the same
values `build_activity()` emits, so the details/state lines stay accurate.
